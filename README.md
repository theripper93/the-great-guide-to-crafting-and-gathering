# The Great Guide to Crafting and Gathering

> **AI disclosure.**  This is a personal project that I made for my own games and am sharing as it is, for free. It contains AI generated content. It contains no generated artwork. You are free to edit and redistribute the content.

A complete crafting and gathering system for D&D 5e (2024 rules) in Foundry VTT. Characters forage, hunt, mine, fish and harvest defeated creatures, then turn what they find into weapons, armor, potions, meals, scrolls, gadgets and more.

It is a content module for [Gatherer](https://foundryvtt.com/packages/gatherer) and [Mastercrafted](https://foundryvtt.com/packages/mastercrafted). Those two modules provide the gathering and crafting mechanics; this one provides everything to gather and craft.

## What is inside

| Content | Count |
| --- | --- |
| Raw materials | 420 |
| Refined materials | 130 |
| Finished goods | 553 |
| Tools and kits | 20 |
| Drop tables and mishap tables | 116 |
| Recipes, in 12 books | 687 |
| Artifacts, each with a step-by-step crafting page | 33 |
| Gathering pages (forest, mountain, sea coast and so on, by tier) | 106 |

Eleven professions use the tool proficiencies of the core rules: smithing, leatherworking, woodworking, tailoring, jewelcrafting, alchemy, poisoncraft, enchanting, scribing, tinkering and cooking. Everything is sorted into four tiers that follow character level, with artifacts above them for level 20 characters.

The module also adds one GM window, **Great Guide Tools**, opened from the top of the Items sidebar:

- **Recipe Tracker** shows what each character has crafted and unlocks recipe tiers or single recipes.
- **Crafting Lookup** answers "where do I find this" and "what is this used for" for any item.
- **Node Placer** drops a ready-made gathering spot on the current scene.

A Player Guide and a GM Guide ship in the **Guides** compendium.

## Requirements

- Foundry VTT version 14
- The dnd5e system, version 6.0.6 or later, with the 2024 rules
- The modules **Gatherer**, **Mastercrafted** and **System Abstraction** (Foundry offers to install them with this module)

## Installation

1. In Foundry's setup screen, open **Add-on Modules** and click **Install Module**.
2. Paste this address into the **Manifest URL** field at the bottom and click **Install**:

   ```text
   https://github.com/theripper93/the-great-guide-to-crafting-and-gathering/releases/latest/download/module.json
   ```

3. Accept the dependencies when Foundry asks.
4. Open your world, go to **Manage Modules** and enable **The Great Guide to Crafting and Gathering** together with its dependencies.
5. When the world reloads, a window offers to import the recipe books and gathering journals. Click **Import**. The same window is available later under **Configure Settings**, **The Great Guide to Crafting and Gathering**, **Import content**.

The import window has two options for tables that want a lighter system: **Crafting takes no time** and **Crafting and gathering need no check**.

After the import, open the GM Guide in the **Guides** compendium. Its first page lists the four steps to a first gather and craft.
